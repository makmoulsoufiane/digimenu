DigiMenu is a full-stack web application for restaurants to manage and publish digital menus.

The application allows restaurant staff to create menus, add menu items, update prices, manage product availability, and organize items by menu. Customers can browse the restaurant’s digital menu and view available products online.

The current version focuses on menu and menu item management, while future versions can add QR codes, table management, customer visits, orders, waiters, and reviews.
